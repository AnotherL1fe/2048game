# 2048 Game 🎮

Классическая игра 2048 с современным дизайном, анимациями и облачным сохранением.

![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![Vite](https://img.shields.io/badge/Vite-4.0-purple)
![License](https://img.shields.io/badge/license-MIT-green)

---

## 📱 Особенности

- ✅ Полноценный геймплей 2048 с плавными анимациями
- ✅ Автосохранение — прогресс сохраняется после каждого хода
- ✅ Адаптивный дизайн — игра отлично выглядит на всех экранах
- ✅ Мобильная поддержка — управление свайпами
- ✅ Анимированные тайлы — появление, слияние, движение
- ✅ Таблица рекордов — сохранение лучшего результата
- ✅ Тёмная тема с эффектом стекла (Glassmorphism)
- ✅ Конфетти при победе и окончании игры
- ✅ Индикатор сохранения — визуальная обратная связь

## 🚀 Установка и запуск

### Требования
- Node.js 16+
- npm или yarn

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-username/2048-game.git

# 2. Перейти в папку проекта
cd 2048-game

# 3. Установить зависимости
npm install

# 4. Запустить в режиме разработки
npm run dev

# 5. Открыть в браузере
# http://localhost:5173
```

### Сборка для продакшена

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`.

## 🔧 Настройка

### Изменение размера поля

В `src/classes/Game.js`:

```javascript
this.tileCount = 4  // 4x4 (стандарт)
// или
this.tileCount = 5  // 5x5
```

### Настройка автосохранения

В `src/classes/Game.js` метод `saveGame()`:

```javascript
// Увеличить задержку между сохранениями
setTimeout(() => this.saveGame(), 1000)
```
